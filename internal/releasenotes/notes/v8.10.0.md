Animations start one level lower, a hidden Disco mode walks the rainbow palette, and stacked selectors stop repeating the same colour.

## ✨ Added

- **Disco mode**, hidden until you find it: every coloured row and item steps to the next colour in the palette once a second, for as long as Rainbow Mode is on. Turn Rainbow Mode on five times in a row to unlock it. It is a colour change, not an animation, so it costs nothing to run.
- **The hidden "Storm" animation level now overrides the system's reduced-motion setting.** The three levels the picker offers still obey it. Storm takes five clicks on the same option, so nobody gets there without meaning to.

## 🐛 Fixed

- **The green flash and the trembling page are both reported at "Wild"** ([#228](https://github.com/junkerderprovinz/bombvault/issues/228)). On Firefox/macOS the coloured badges flash `#38FF38`; on Chromium there is no green and the page trembles before it settles. Setting animations to off stops both. **Correction, added after release:** this entry named a mechanism, nested transforms each taking a compositing layer and the badges painting out of uninitialised layer memory. That was inferred from the code and never measured, and a later release built on it without fixing the flash. The cause is still open.
- **Animations now start at "Subtle"**: 6px, no tilt, no scale. Nobody had chosen the top level, it was simply what shipped. **Wild** is unchanged and still available under Settings, General, Animations.
- **A strong-level choice made before the setting was renamed carries over** instead of being reset to the new default.
- **Stacked selectors no longer wear the same colour in the same column** in Rainbow Mode. Each one starts further along the palette, so the three label-mode rows read as three rows instead of one repeated three times.

## 🔍 Not verified here

- The green flash was traced in the code and from the reporter's recordings. There is no macOS machine with Firefox on this side, so that the flash stops is a conclusion, not an observation.
